# Kitty SSH Themes - Быстрый старт

## Что это?

Автоматическая смена темы Kitty terminal для визуального различия между локальной работой и SSH-подключениями.

## Визуальные индикаторы

| Окружение | Цвет фона | Цвет вкладок | Значение |
|-----------|-----------|--------------|----------|
| Локаль    | Светлый   | Зеленый      | ✅ Безопасно |
| SSH       | Темный    | Красный      | 🚨 Удаленный |
| Продакшн  | Темно-красный | Красный  | 🔴 Опасность |
| Стагинг   | Темно-оранжевый | Оранжевый | 🟠 Внимание |
| Дев       | Темно-синий | Синий    | 🔵 Спокойствие |

## Установка за 30 секунд

```bash
# 1. Установите (один раз)
./install-kitty-themes.sh

# 2. Для нового проекта
cd /path/to/project
../copy-kitty-files-to-project.sh .

# 3. Если используете direnv
direnv allow
```

## Использование

Автоматически: тема меняется при `cd` в каталог проекта или при SSH-подключении

Вручную:
```bash
kitty-switch-theme.sh local    # Локальная тема
kitty-switch-theme.sh prod     # Продакшн (красная)
kitty-switch-theme.sh staging  # Стагинг (оранжевая)
kitty-switch-theme.sh dev      # Девелопмент (синяя)
```

## Файлы

- `kitty-themes/` - 5 тем для разных окружений
- `kitty-switch-theme*.sh` - Скрипты переключения
- `.envrc` - Конфигурация direnv
- `SSH_THEME_SETUP.md` - Полная документация

## Требования

- Kitty terminal с `allow_remote_control yes` в конфиге
- direnv (опционально, для автоматического переключения)
