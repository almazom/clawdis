## 2. Slash Commands

| Command | Description |
|---------|-------------|
| `/collection list` | List all collections |
| `/collection show <name>` | Show collection details |
| `/collection create` | Create new collection via UI |
| `/collection add <name> <url>` | Add resource to collection |
| `/collection remove <name> <url>` | Remove resource |
| `/collection delete <name>` | Delete collection |
| `/collection analyze <name> <q>` | Analyze collection |
| `/collection report <name>` | Generate report |
| `/collection menu` | Show collection menu |

---

## 3. Callback Data Structure

```typescript
type CollectionCallbackData =
  | { action: 'list' }
  | { action: 'show'; collection: string }
  | { action: 'create_step1' }
  | { action: 'create_step2'; name: string }
  | { action: 'create_step3'; name: string; description: string }
  | { action: 'add_source'; collection: string }
  | { action: 'remove_source'; collection: string; url: string }
  | { action: 'delete'; collection: string }
  | { action: 'report'; collection: string }
  | { action: 'analyze'; collection: string; prompt?: string }
  | { action: 'refresh'; collection: string }
  | { action: 'back' }
```
