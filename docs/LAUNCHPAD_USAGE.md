# Launchpad Docs Usage (Skills)

Use Launchpad documents as the canonical workflow for skills that depend on ordered procedures.

## Source of truth rule

- Always read `docs/Launchpad/TELEGA_E2E_PIPELINE.md` when the request is “Telega-e2e”.
- Follow the pipeline exactly unless the user explicitly asks for deviations.
- If a skill needs additional context or is updated, update the Launchpad document first and keep the skill body in sync.

## When to use

- When the user asks for an end-to-end Telegram validation run.
- When a skill needs a reproducible, step-by-step procedure.
